# Design documents

Dated design specs and implementation plans, one set per feature.

These are historical records. They describe the repository as it was on the date
in the file name, so their file paths can be out of date. The specs written
before version 1.0.0 refer to `scripts/theme-toggle.js`, which is now
`extensions/toggle-dark/theme-toggle.js`. Read `CHANGELOG.md` for the moves.

Do not edit a document after its feature ships. Write a new dated document.
